# grom обходник v1.8

Графическая обёртка над winws (zapret, автор — bol-van) для обхода блокировок DPI.
Один exe-файл: `grom.exe`, без консольных окон.

## Скачать

**Нужна готовая программа?** → [Релизы](https://github.com/frogiiiiiiii1/grom/releases),
там в самом низу «Assets» → скачать `grom.exe`. Запустить двойным кликом,
подтвердить UAC. Больше ничего не нужно.

**Эта папка (исходники)** — только код для разработки, запускать тут нечего.

**Внутри exe уже встроен дистрибутив zapret** (winws.exe, драйвер WinDivert,
списки и стратегии, ~4 МБ). Работает на чистом ПК без отдельной папки zapret:
при первом запуске распаковывается в `%LOCALAPPDATA%\grom\zapret`.

Если на ПК есть своя папка zapret — grom использует её (встроенная копия
остаётся про запас).

## Возможности

- **Главная** — настоящая круглая кнопка запуска (рисуется на Canvas, поэтому
  всегда идеально круглая при любом масштабе экрана): дыхание подсветки,
  эффект нажатия, плавная смена фиолетового/красного; статус-пилюля, лог winws,
  выбор папки zapret
- Переключатель **«запускать обход при открытии программы»** — обход стартует сам
- **⚙** — выбор стратегии из .bat-файлов и правка аргументов winws
- **Автозапуск** — задача планировщика «grom»: обход при входе в Windows, без окон
- **Игры** — живой FPS и график фреймтаймов выбранной игры через PresentMon
  (официальная утилита Intel, встроена в exe): текущий FPS, средний, 1% low,
  время кадра в мс; плюс загрузка процессора, видеокарты и памяти в реальном
  времени. Замер идёт в фоне — можно сворачивать grom и играть
- **Тема** — 5 цветовых тем (Ночной фиолет, Океан, Малахит, Магма, Монохром),
  свой акцентный цвет (8 готовых или свой через палитру Windows), картинка на фон
  с затемнением, настройка скругления углов; всё применяется сразу, без перезапуска
- Анимации: плавный выезд страниц, проявление элементов сайдбара при старте,
  растущий индикатор активного раздела, «дышащие» статусные точки
- Если найден чужой winws (служба/батник) — программа предлагает остановить его,
  чтобы фильтры не пересекались

## Использование

1. Запустите `grom.exe`, подтвердите UAC
2. Нажмите круглую кнопку ▶ — обход запущен (кнопка станет ■)
3. Нажмите ещё раз ■ — обход остановлен

## Пересборка

```
pip install customtkinter pillow pyinstaller
pyinstaller --noconfirm --onefile --noconsole --name "grom" ^
    --icon "grom_icon.ico" ^
    --add-data "zapret_bundle;zapret_bundle" ^
    --add-data "tools;tools" ^
    --add-data "grom_icon.ico;." zapret_gui.py
```

Папка `zapret_bundle` — это копия дистрибутива zapret, которая встраивается в exe.
Папка `tools` — встроенный PresentMon (замер FPS), распаковывается в
`%LOCALAPPDATA%\grom\tools`.
Иконка (`grom_icon.ico`) встраивается в exe и показывается в сайдбаре —
генерируется скриптом `gen_icon.py`.
