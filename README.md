# grom v1.5

Графическая обёртка над winws (zapret, автор — bol-van) для обхода блокировок DPI.
Один exe-файл: `Desktop\grom.exe`, без консольных окон.

**Внутри exe уже встроен дистрибутив zapret** (winws.exe, драйвер WinDivert,
списки и стратегии, ~4 МБ). Работает на чистом ПК без отдельной папки zapret:
при первом запуске распаковывается в `%LOCALAPPDATA%\grom\zapret`.

Если на ПК есть своя папка zapret — grom использует её (встроенная копия
остаётся про запас).

## Возможности

- **Главная** — одна круглая кнопка с пульсацией: нажмите, чтобы запустить/
  остановить обход; статус-пилюля, лог winws, выбор папки zapret
- Переключатель **«запускать обход при открытии программы»** — обход стартует сам
- **⚙** — выбор стратегии из .bat-файлов и правка аргументов winws
- **Автозапуск** — задача планировщика «grom»: обход при входе в Windows, без окон
- Если найден чужой winws (служба/батник) — программа предлагает остановить его,
  чтобы фильтры не пересекались

## Использование

1. Запустите `grom.exe`, подтвердите UAC
2. Нажмите круглую кнопку ▶ — обход запущен (кнопка станет ■)
3. Нажмите ещё раз ■ — обход остановлен

## Пересборка

```
pip install customtkinter pyinstaller
pyinstaller --noconfirm --onefile --noconsole --name "grom" ^
    --add-data "zapret_bundle;zapret_bundle" zapret_gui.py
```

Папка `zapret_bundle` — это копия дистрибутива zapret, которая встраивается в exe.
